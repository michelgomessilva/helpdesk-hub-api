Bibliotecas  que  vamos  usar  
FastAPI  
Framework  para  criar  APIs  em  Python  com  rapidez  e  organização.  
Instalação:  
uv  add  fastapi  

--- PAGE 3 ---

Uvicorn  
Servidor  que  executa  a  aplicação  FastAPI.  
Instalação:  
uv  add  uvicorn  
Pydantic  
Valida  e  organiza  os  dados  que  entram  e  saem  da  API.  
Instalação:  
uv  add  pydantic  
python-dotenv  
Permite  ler  variáveis  de  ambiente  de  um  arquivo  .env.  
Instalação:  
uv  add  python-dotenv  
SQLAlchemy  
Ferramenta  que  ajuda  a  trabalhar  com  banco  de  dados  usando  Python.  
Instalação:  
uv  add  sqlalchemy  
psycopg  
Driver  de  conexão  com  PostgreSQL.  
Instalação:  
uv  add  "psycopg[binary]"  
Alembic  
Ferramenta  para  criar  e  controlar  migrações  do  banco.  
Instalação:  

--- PAGE 4 ---

uv  add  alembic  
python-jose  
Usada  para  gerar  e  validar  JWT.  
Instalação:  
uv  add  "python-jose[cryptography]"  
passlib  
Usada  para  gerar  hash  seguro  de  senhas.  
Instalação:  
uv  add  "passlib[bcrypt]"  
pytest  
Usada  para  escrever  testes  automatizados.  
Instalação:  
uv  add  --dev  pytest  
httpx  
Usada  para  consumir  APIs  externas.  
Instalação:  
uv  add  httpx  
Loguru  
Usada  para  criar  logs  mais  claros  e  organizados.  
Instalação:  
uv  add  loguru
